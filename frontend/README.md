# Фронтенд: семейный банкинг в Moby

React 18 + Vite + TypeScript + Tailwind. Мобильный экран 390–430px, демо-переключатель Мама / Миша (10) / Аня (15).

## Запуск

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

Без настроек работает **mock**: «бэкенд в браузере» с демо-семьёй и теми же правилами оплаты, что в `docs/api.md`.
Перезагрузка страницы = сброс демо-данных.

## Подключение настоящего бэкенда

```bash
cp .env.example .env    # VITE_API_URL=/api
```

Запросы на `/api` прокси Vite пересылает бэкенду на `http://127.0.0.1:8000` (см. `vite.config.ts`).
Все запросы идут через один интерфейс `Api` (`src/api/index.ts`): `real.ts` — fetch на FastAPI, `mock.ts` — in-memory.
Заголовок `X-User-Id` берётся из демо-переключателя.

## Показать на телефоне

```bash
npm run dev -- --host            # в одной Wi-Fi сети: http://<IP-компьютера>:5173
# или туннель: cloudflared tunnel --url http://localhost:5173
```

## Структура

- `src/api/` — контракт (`index.ts`), fetch-клиент (`real.ts`), mock (`mock.ts`)
- `src/screens/parent.tsx` — главная, оформление пакета, управление ребёнком, запросы, задания
- `src/screens/child.tsx` — главная, симулятор оплаты, запрос родителю, цели, задания, уровень
- `src/ui.tsx`, `src/nav.tsx`, `src/hooks.ts` — общие компоненты, навигация, загрузка данных

1. Мама: «Оформить пакет» → ребёнок 7–13 → согласия → карта выпущена → пополнить.

4. Миша: «Я сделал(а)» в заданиях → Мама подтверждает → уровень 3 → предложение открыть подписки.
